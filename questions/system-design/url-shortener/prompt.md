# Design a URL Shortener

Design a service like **bit.ly** that takes a long URL and returns a short link. Visiting the short link redirects the user to the original URL.

You have about **45 minutes**. Drive the conversation as you would in a real interview:

1. **Clarify requirements.** Ask the interviewer about features and scale. They have the numbers.
2. **Estimate** traffic, storage, and bandwidth.
3. **Define the API** and the data model.
4. **Draw the high-level design** on the whiteboard tab.
5. **Deep-dive** into the hardest parts and discuss tradeoffs and bottlenecks.

Use the **Whiteboard** tab to draw, and the **Notes** tab (markdown) to write requirements, estimates, APIs, schemas, and tradeoffs. The interviewer sees both when you send a message.
